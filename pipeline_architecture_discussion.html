Section 2 — Pros and cons
What each option does well and where the risks sit
Option AVideo + JSON → Nemotron
Pros
Both inputs ground Nemotron — JSON confirms what the video shows, reduces hallucination
Clean structured JSON output from Nemotron → straightforward Claude handoff
worst_rep_number explicit in Nemotron output — no ambiguity for OpenCV Step 2
Test C already planned — scripts ready to run this week
Smaller Claude context — Nemotron does the heavy analysis
Cons
Asking Nemotron to do both visual analysis AND numerical angle comparison — mixing its strengths
Gold standard angle comparison is a reasoning task — Claude may do this better
Harder to debug — if coaching is poor, was it visual analysis or angle reasoning that failed?
Option BVideo only → Nemotron
Pros
Clean separation — Nemotron does vision, Claude does reasoning
Gold standard angle comparison goes to Claude — more reliable numerical reasoning
All quantitative context in one place for Claude — coherent reasoning
Two-phase SSE — user sees coaching text fast, frame loads separately
Easier to debug — clear responsibility boundary
Cons
Nemotron without JSON may produce vague or unstructured output — Test A results critical
Larger Claude context — Nemotron text + biomechanics JSON + gold standard + history + RAG
worst_rep_number must be explicit structured field in Claude's output or OpenCV Step 2 fails
Two-phase SSE requires more frontend complexity
Option C · NewBiomechanics angles → Claude
Pros
No Nemotron — removes one API call, reduces latency, removes a failure point
Pure quantitative reasoning — Claude compares user angles against gold standard distributions directly, which is exactly what LLM reasoning excels at
Gold standard DB becomes richer over time — more reference videos = better angle distributions, improving analysis quality without retraining
Cheaper per-analysis — one model API call instead of two
Simpler pipeline — fewer integration points between squads
OpenCV overlay video not required — saves processing time in Squad 3
Cons
No visual analysis — Claude cannot detect form issues that are visible in the video but not captured in the angles (e.g. bar path, chest positioning, foot placement)
Entirely dependent on biomechanics script accuracy — if an angle is computed incorrectly, the whole coaching is wrong with no visual check
Gold standard DB needs sufficient volume (3–5 is minimum — more is better) to produce reliable angle distributions
Removes Nemotron from the stack — investment in API access and test plan wasted

Key questions for the team
Question 1 — Does video add value over angles alone?
Compare Test A (Nemotron video-only) output against Option C (Claude angles-only) output on the same video. Does seeing the video allow identification of form issues that the biomechanics angles miss entirely?
If yes → keep Nemotron (Option A or B). If no → Option C is the simplest and cheapest architecture.
Question 2 — How many gold standard videos does Option C need to be reliable?
Option C's quality improves as the gold standard DB grows. 3–5 videos gives angle ranges. 10–20 gives statistical distributions. At what volume does the angle comparison become credible enough for coaching?
This determines the data prep investment required before Option C is viable in production.
Question 3 — Does Nemotron in Test A produce worst_rep_number explicitly?
OpenCV Step 2 needs a rep index to seek to. Options A and B depend on this being a structured output field. If Nemotron doesn't produce it reliably, Claude must derive it — which works in Options B and C but requires explicit prompt engineering.
If Nemotron does produce it reliably → Option A gains an advantage. If not → Options B and C handle this more gracefully via Claude or biomechanics data.
Recommendation — pending test results
Run all four comparisons before committing. The Nemotron A/B/C tests are already planned. Add a fourth test: send user biomechanics angles + gold standard angles directly to Claude with no Nemotron call. Compare the four outputs side by side.

If Option C coaching quality ≈ Option A or B: Choose Option C — no Nemotron, lower cost, simpler pipeline, faster latency, and the gold standard DB improves over time without code changes.

If Nemotron (A or B) clearly outperforms Option C: The video is adding meaningful form insight that angles alone miss — keep Nemotron and choose between A and B based on Test A vs Test C quality delta.

Regardless of option: Two-phase SSE delivery (coaching text first, frame second) improves UX and works with any of the three architectures.
