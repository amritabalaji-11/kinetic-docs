Feature Details

🔐 1. Build Authentication (Google Layer)

What: Replace demo user selection with real Google Sign-In

Why: Need real user tracking for all other features

✅ Scope:
  • Google OAuth 2.0
  • JWT generation
  • User provisioning
  • Session management
🎯 Status: MVP Build #1
⚡ Priority: Foundation
🔗 Unblocks: Everything else

💭 Decision Points

  • Implement full OAuth or simplified version?
  • Store profiles in auth service or DB?

🏋️ 2. Select 5 Exercises

What: Choose which 5 exercises to support in MVP

Why: Need enough variety for market relevance, but manageable scope

💪 Options to Discuss:
A) Lower Body: Goblet, Barbell, Deadlift, Leg Press, RDL
B) Mixed: Squat, Bench, Deadlift, Row, Shoulder Press
C) Beginner: Goblet, Dumbbell Row, Leg Press, Dumbbell Press, Lunge
🎯 Status: MVP Build #2
⚡ Priority: High
🔗 Depends on: #1

💭 Decision Points

  • Which 5 exercises based on market research?
  • New exercises or mostly existing (easier)?
  • In-house PT videos or sourced?

📋 3. Workout Builder Backend

What: Persist workout plans and logged sessions to database

Why: Currently frontend-only, data lost on browser clear

✅ Implementation:
  • Create workouts table
  • Build 4 API endpoints
  • Frontend integration
  • Session persistence
🎯 Status: MVP Build #3
⚡ Priority: High
🔗 Depends on: #2

💭 Decision Points

  • Include workout templates?
  • Support workout notes/comments?
  • Rep-by-rep or just sets/reps/weight?

🤖 4. RAG Injection for Feedback

What: Inject exercise-specific content into Haiku coaching prompts

Why: Provide targeted, not generic coaching

✅ Components:
  • Content library per exercise
  • RAG system (search/embed)
  • Haiku integration
  • Rich coaching output
🎯 Status: MVP Build #4
⚡ Priority: High
🔗 Depends on: #2, #3

💭 Decision Points

  • Vector DB (Pinecone, Weaviate) or simple search?
  • Content depth per exercise (5 vs 20 pages)?
  • Include research papers or practical guides?

📊 5. Improve Pose Detection

What: Fix MediaPipe accuracy (e.g., goblet squat front angle issue)

Why: Current thresholds may be inaccurate, affects all scores

✅ Scope:
  • Calibration study
  • Manual annotation
  • Error analysis
  • Threshold adjustment
🎯 Status: Future
⚡ Priority: Medium
🔗 Depends: None

💭 Decision Points

  • Invest in calibration now or accept current accuracy?
  • Focus on worst-performing exercises?
  • A/B test improved thresholds with users?

🎥 6. PT Videos (2-3 Per Exercise)

What: Record PT demonstrating proper form at multiple angles

Why: Visual reference builds user confidence

✅ Per Exercise:
  • Video 1: Full rep (front)
  • Video 2: Key angles (side)
  • Video 3: Common faults
🎯 Status: Future
⚡ Priority: Medium
🔗 Depends on: #2

💭 Decision Points

  • Internal PT or hire external?
  • Professional production or DIY?
  • Where to host (YouTube, internal CDN)?

👁️ 7. Photo/Video Overlay

What: Show annotated video with skeleton overlay + angle labels

Why: Visual proof builds trust ("here's where we measured")

✅ Scope:
  • Skeleton visualization
  • Angle annotations
  • Frame-by-frame display
  • Timeline chart
🎯 Status: Future
⚡ Priority: Medium
🔗 Depends on: #5

💭 Decision Points

  • Full video playback or just key frames?
  • Interactive scrubbing or auto-play?
  • Compare against PT reference video?

💡 8. Form Cues in Workout Logger

What: Display exercise-specific form guidance while logging sets

Why: User about to do reps, show what to focus on

✅ Scope:
  • Fetch form cues from Haiku
  • Display in logger UI
  • Link to PT videos
  • Dynamic updates
🎯 Status: Future
⚡ Priority: Medium
🔗 Depends on: #4

💭 Decision Points

  • Show all cues or just #1 priority?
  • Auto-play PT video or just link?
  • Allow user to set custom focus area?

📱 9. Mobile App (Native)

What: Build native iOS/Android app

Why: Fitness apps need native capabilities (camera, notifications, offline)

✅ Core Features:
  • Video recording
  • Upload & analysis
  • View results
  • Workout logger
🎯 Status: Future
⚡ Priority: Lower
🔗 Depends on: MVP stability

💭 Decision Points

  • Native vs React Native/Flutter?
  • MVP feature set or full parity?
  • iOS first or simultaneous iOS + Android?

⚡ 10. GPU-Optimized MediaPipe

What: Move MediaPipe processing to GPU for latency improvements

Why: Reduce video analysis time (currently ~20-30s), improve user experience

✅ Components:
  • GPU-enabled MediaPipe model
  • CUDA/Metal/OpenGL support
  • Tensor optimization
  • Performance benchmarking
🎯 Status: Future
⚡ Priority: Medium
🔗 Depends on: Stable MediaPipe baseline

💭 Decision Points

  • Build on CPU first, optimize to GPU later?
  • Target which GPU platforms (NVIDIA, Apple Metal)?
  • Acceptable latency target (10s? 15s?)?

MVP Build Sequence

Build Order for First 4 Features

✅ Feature 1: Authentication (Google) └─ Foundation for everything ✅ Feature 2: Select 5 Exercises └─ Needed for features 3 & 4 ✅ Feature 3: Workout Builder Backend └─ Persist user workout data ✅ Feature 4: RAG Injection └─ Enhanced coaching with exercise content → Future Features (discuss separately): Features 5-9 (Pose Detection, PT Videos, Overlay, Form Cues, Mobile)
