## 💡 How to Use This Template

### Step 1: Start with TL;DR
Write your one-sentence pitch first. If you can't explain it in one sentence, it's too complex.

### Step 2: Define Success
Pick ONE north star metric. Everything else is supporting or anti-metrics.

### Step 3: Ruthlessly Prioritize
Only P0 features in MVP. Everything else goes to P1/P2 or out of scope.

### Step 4: Set Clear Launch Criteria
Make these binary checkboxes. If you can't check all boxes, you can't ship.

### Step 5: Keep It Living
Update the PRD as you learn. Don't let it become stale documentation.

---

## ✅ Best Practices

**DO:**
- ✅ Keep it concise (2-4 pages max)
- ✅ Use data to back up decisions
- ✅ Include actual user quotes
- ✅ Define clear acceptance criteria
- ✅ Update regularly as you learn

**DON'T:**
- ❌ Write this alone (get input early)
- ❌ Over-specify implementation details
- ❌ Skip the "out of scope" section
- ❌ Forget to define success metrics
- ❌ Let it become outdated
