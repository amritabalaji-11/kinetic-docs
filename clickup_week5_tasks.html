Implementation — SSE Client (browser EventSource API)
How SSE works: SSE is a one-way persistent HTTP connection — the server pushes events as the pipeline progresses without the frontend polling. The browser's native EventSource API handles reconnection automatically.

Connection lifecycle:
1. Frontend POSTs video to /upload → receives analysis_id immediately
2. Frontend opens EventSource using that analysis_id — connection stays open while pipeline runs
3. Each pipeline stage emits an event → frontend maps it to a UI state update
4. Frontend closes the connection on analysis_complete or on any error event

React implementation pattern: 
const es = new EventSource(`/api/stream?analysis_id=${analysisId}`)

es.onmessage = (e) => {
  const { event, ...payload } = JSON.parse(e.data)
  dispatch(updatePipelineStage({ event, payload }))
  if (event === 'analysis_complete') es.close()
}

es.onerror = () => {
  dispatch(setPipelineError({ retryable: true }))
  es.close()  // do not let EventSource auto-reconnect mid-pipeline
}
Important: Always call es.close() explicitly in the error handler — browser auto-reconnect is not appropriate mid-pipeline. Each event payload carries analysis_id so concurrent uploads on the same tab cannot mix state.

Implementation — SSE Stream (FastAPI StreamingResponse)
How SSE works on the backend: FastAPI returns a StreamingResponse with media_type="text/event-stream". An async generator function yields each event as a pipeline stage completes. The connection stays open until the final event is yielded.

Event format: Every yielded string must follow the SSE spec exactly — data: {json}\n\n — the double newline is required to signal the end of one event to the browser.

FastAPI stub implementation: 
from fastapi.responses import StreamingResponse
from fastapi import UploadFile
from uuid import uuid4
import asyncio, json

async def pipeline_stream(analysis_id: str):
    yield f"data: {json.dumps({'event': 'upload_received',     'analysis_id': analysis_id})}\n\n"
    await asyncio.sleep(0.5)
    yield f"data: {json.dumps({'event': 'mediapipe_started',   'analysis_id': analysis_id})}\n\n"
    await asyncio.sleep(1.5)
    yield f"data: {json.dumps({'event': 'mediapipe_complete',  'analysis_id': analysis_id, 'rep_count': 8})}\n\n"
    await asyncio.sleep(0.5)
    yield f"data: {json.dumps({'event': 'nemotron_started',    'analysis_id': analysis_id})}\n\n"
    await asyncio.sleep(2.0)
    yield f"data: {json.dumps({'event': 'nemotron_complete',   'analysis_id': analysis_id, 'overall_score': 72})}\n\n"
    await asyncio.sleep(0.5)
    yield f"data: {json.dumps({'event': 'rag_started',         'analysis_id': analysis_id})}\n\n"
    await asyncio.sleep(1.0)
    yield f"data: {json.dumps({'event': 'rag_complete',        'analysis_id': analysis_id, 'passages_retrieved': 8})}\n\n"
    await asyncio.sleep(0.5)
    yield f"data: {json.dumps({'event': 'claude_started',      'analysis_id': analysis_id})}\n\n"
    await asyncio.sleep(1.5)
    yield f"data: {json.dumps({'event': 'claude_complete',     'analysis_id': analysis_id})}\n\n"
    yield f"data: {json.dumps({'event': 'analysis_complete',   'analysis_id': analysis_id})}\n\n"

@app.post("/upload")
async def upload(file: UploadFile):
    analysis_id = str(uuid4())
    return StreamingResponse(
        pipeline_stream(analysis_id),
        media_type="text/event-stream",
        headers={"Cache-Control": "no-cache", "X-Accel-Buffering": "no"}
    )
⚠ Critical — X-Accel-Buffering: no: Without this header, nginx (used by Cloud Run) buffers the entire stream and delivers all events in a single batch at the end — the progressive UI never updates mid-analysis. This header disables that buffering.

⚠ Critical — Cache-Control: no-cache: Required by the SSE spec. Without it, some proxies and browsers cache the response instead of keeping the connection live.

Every event payload must carry analysis_id — this is what lets the frontend match events to the correct upload when a user submits multiple sessions.

    Implementation Reference — Landmark Quality Analysis Functions
    Purpose of these functions: Determine which frames are reliable enough to pass to biomechanics computation and the LLM. MediaPipe outputs two separate quality scores per landmark per frame:
    • visibility — is the landmark occluded or obscured? (0–1). Low = hidden behind body, clothing, or object.
    • presence — is the landmark within the camera frame at all? (0–1). Low = body part outside camera view.
    Both must exceed threshold for the landmark to be usable. A landmark can be in-frame but occluded (low visibility, high presence) or outside the frame entirely (low presence).

    Shared setup — landmarks + thresholds: 
    import mediapipe as mp
import cv2
import numpy as np
from collections import defaultdict

# Landmarks relevant to Goblet Squat — index : name
SQUAT_LANDMARKS = {
    11: "left_shoulder",  12: "right_shoulder",
    23: "left_hip",       24: "right_hip",
    25: "left_knee",      26: "right_knee",
    27: "left_ankle",     28: "right_ankle",
    29: "left_heel",      30: "right_heel",
}

VISIBILITY_THRESHOLD = 0.70   # landmark occluded below this
PRESENCE_THRESHOLD   = 0.70   # landmark out-of-frame below this

def _is_reliable(lm) -> bool:
    return lm.visibility >= VISIBILITY_THRESHOLD and lm.presence >= PRESENCE_THRESHOLD
    Function 1 — Global average across the full video:
    Returns per-landmark average visibility + presence, plus every frame and timestamp where a landmark drops below threshold (angle computation cannot be trusted at those frames). 
    def analyze_global_landmark_quality(video_path: str) -> dict:
    cap  = cv2.VideoCapture(video_path)
    fps  = cap.get(cv2.CAP_PROP_FPS)
    pose = mp.solutions.pose.Pose(static_image_mode=False, model_complexity=1)

    stats = {name: {"visibility": [], "presence": [], "flagged_frames": []}
             for name in SQUAT_LANDMARKS.values()}

    frame_index = 0
    while cap.isOpened():
        ret, frame = cap.read()
        if not ret:
            break
        timestamp_ms = round((frame_index / fps) * 1000, 1)
        result = pose.process(cv2.cvtColor(frame, cv2.COLOR_BGR2RGB))

        if result.pose_landmarks:
            for idx, name in SQUAT_LANDMARKS.items():
                lm = result.pose_landmarks.landmark[idx]
                stats[name]["visibility"].append(lm.visibility)
                stats[name]["presence"].append(lm.presence)

                if not _is_reliable(lm):
                    stats[name]["flagged_frames"].append({
                        "frame_index":  frame_index,
                        "timestamp_ms": timestamp_ms,
                        "visibility":   round(lm.visibility, 3),
                        "presence":     round(lm.presence, 3),
                        "reason":       "low_visibility" if lm.visibility < VISIBILITY_THRESHOLD
                                        else "out_of_frame"
                    })
        frame_index += 1

    cap.release()

    return {
        name: {
            "avg_visibility":     round(float(np.mean(d["visibility"])), 3),
            "avg_presence":       round(float(np.mean(d["presence"])), 3),
            "reliable_pct":       round(
                sum(1 for v, p in zip(d["visibility"], d["presence"])
                    if v >= VISIBILITY_THRESHOLD and p >= PRESENCE_THRESHOLD)
                / max(len(d["visibility"]), 1) * 100, 1),
            "flagged_frame_count": len(d["flagged_frames"]),
            "flagged_frames":      d["flagged_frames"],
        }
        for name, d in stats.items()
    }
    Function 2 — Per-rep breakdown (same stats, segmented by rep):
    Accepts rep_segments — a list of (start_frame, end_frame) tuples. These segments will be provided by S3-W5-07's rep segmentation algorithm. For this spike, approximate rep boundaries manually by watching the video and noting frame numbers. 
    def analyze_per_rep_landmark_quality(video_path: str,
                                       rep_segments: list[tuple[int,int]]) -> list:
    """
    rep_segments: [(start_frame, end_frame), ...]  — one tuple per rep
    Returns one result dict per rep in the same format as analyze_global_landmark_quality.
    """
    cap  = cv2.VideoCapture(video_path)
    fps  = cap.get(cv2.CAP_PROP_FPS)
    pose = mp.solutions.pose.Pose(static_image_mode=False, model_complexity=1)

    # collect all frame results first
    all_frames = {}
    frame_index = 0
    while cap.isOpened():
        ret, frame = cap.read()
        if not ret:
            break
        timestamp_ms = round((frame_index / fps) * 1000, 1)
        result = pose.process(cv2.cvtColor(frame, cv2.COLOR_BGR2RGB))
        if result.pose_landmarks:
            all_frames[frame_index] = {
                "timestamp_ms": timestamp_ms,
                "landmarks": {
                    name: result.pose_landmarks.landmark[idx]
                    for idx, name in SQUAT_LANDMARKS.items()
                }
            }
        frame_index += 1
    cap.release()

    # slice into reps and compute stats per rep
    results = []
    for rep_num, (start_f, end_f) in enumerate(rep_segments, start=1):
        rep_frames = {f: d for f, d in all_frames.items() if start_f <= f <= end_f}
        stats = {name: {"visibility": [], "presence": [], "flagged_frames": []}
                 for name in SQUAT_LANDMARKS.values()}

        for f_idx, f_data in rep_frames.items():
            for name, lm in f_data["landmarks"].items():
                stats[name]["visibility"].append(lm.visibility)
                stats[name]["presence"].append(lm.presence)
                if not _is_reliable(lm):
                    stats[name]["flagged_frames"].append({
                        "frame_index":  f_idx,
                        "timestamp_ms": f_data["timestamp_ms"],
                        "visibility":   round(lm.visibility, 3),
                        "presence":     round(lm.presence, 3),
                        "reason":       "low_visibility" if lm.visibility < VISIBILITY_THRESHOLD
                                        else "out_of_frame"
                    })

        results.append({
            "rep":           rep_num,
            "start_frame":   start_f,
            "end_frame":     end_f,
            "start_ms":      all_frames.get(start_f, {}).get("timestamp_ms"),
            "end_ms":        all_frames.get(end_f,   {}).get("timestamp_ms"),
            "landmark_quality": {
                name: {
                    "avg_visibility":      round(float(np.mean(d["visibility"])), 3)  if d["visibility"] else None,
                    "avg_presence":        round(float(np.mean(d["presence"])), 3)    if d["presence"]   else None,
                    "reliable_pct":        round(
                        sum(1 for v, p in zip(d["visibility"], d["presence"])
                            if v >= VISIBILITY_THRESHOLD and p >= PRESENCE_THRESHOLD)
                        / max(len(d["visibility"]), 1) * 100, 1),
                    "flagged_frame_count": len(d["flagged_frames"]),
                    "flagged_frames":      d["flagged_frames"],
                }
                for name, d in stats.items()
            }
        })
    return results
