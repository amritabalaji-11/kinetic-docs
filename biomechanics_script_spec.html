What this script does
Receives an array of selected, quality-gated frames from S3-W5-06. Each frame carries world landmark coordinates (3D metric), screen landmark coordinates (normalised), visibility scores, rep_index, and position_tag (top / bottom / null).

For each rep, computes: joint angles at key positions, tempo metrics, stability signals, error flags, and frame reliability. Aggregates all reps into a consolidated summary with cross-rep trends. Outputs a single JSON passed to the LLM stage.

One object per frame. Biomechanics script receives an array of these for all frames that passed the visibility gate.

Calculations — Tempo
Tempo Eccentric · Pause · Concentric · Total · Notation
ℹ Tempo is computed from a state machine tracking hip angle over time. Each phase transition is timestamped using timestamp_ms from the frame payload. Thresholds: hip < 100° = descending · hip < 90° = bottom · hip > 160° = standing.
# State machine — runs across frames ordered by timestamp_ms
class TempoTracker:
  def update(self, hip_angle, timestamp_ms):
    if self.state == "STANDING" and hip_angle < 100:
      self.state = "DESCENDING"; self.t_start = timestamp_ms
    elif self.state == "DESCENDING" and hip_angle < 90:
      self.eccentric = (timestamp_ms - self.t_start) / 1000
      self.state = "BOTTOM"; self.t_start = timestamp_ms
    elif self.state == "BOTTOM" and hip_angle > 100:
      self.pause = (timestamp_ms - self.t_start) / 1000
      self.state = "ASCENDING"; self.t_start = timestamp_ms
    elif self.state == "ASCENDING" and hip_angle > 160:
      self.concentric = (timestamp_ms - self.t_start) / 1000
      self.total = self.eccentric + self.pause + self.concentric
      return self._build_output()

# Back angle — torso lean from vertical (world coords)
def back_angle(shoulder, hip):
  torso = np.array([shoulder.x - hip.x, shoulder.y - hip.y, shoulder.z - hip.z])
  vertical = np.array([0, -1, 0])
  return np.degrees(np.arccos(np.dot(torso, vertical) / np.linalg.norm(torso)))

# Average left + right side
angle = (back_angle(lm[11], lm[23]) + back_angle(lm[12], lm[24])) / 2

# Butt wink — posterior pelvic tilt at bottom (S3-W5-07 post-processing)
def butt_wink(shoulder, hip, knee, baseline_angle):
  torso_vec = hip - shoulder
  pelvis_vec = knee - hip
  angle = np.degrees(np.arccos(np.dot(torso_vec, pelvis_vec) / (norm(torso_vec) * norm(pelvis_vec))))
  deviation = angle - baseline_angle
  return deviation > 15, deviation # (detected: bool, severity_deg: float)

Calculations — Movement Quality
Movement Quality Depth · Hip Angle · Ankle Dorsiflexion · Foot Turn-out
# Hip angle (shoulder→hip→knee) — primary depth metric
def hip_angle(shoulder, hip, knee): # world coords
  v1 = shoulder - hip; v2 = knee - hip
  return np.degrees(np.arccos(np.clip(np.dot(v1,v2)/(norm(v1)*norm(v2)),-1,1)))

# Knee angle (hip→knee→ankle)
def knee_angle(hip, knee, ankle): # world coords
  v1 = hip - knee; v2 = ankle - knee
  return np.degrees(np.arccos(np.clip(np.dot(v1,v2)/(norm(v1)*norm(v2)),-1,1)))

# Ankle dorsiflexion (knee→ankle→foot_index)
def ankle_dorsiflexion(knee, ankle, foot_index): # world coords
  v1 = knee - ankle; v2 = foot_index - ankle
  return np.degrees(np.arccos(np.clip(np.dot(v1,v2)/(norm(v1)*norm(v2)),-1,1)))

# Foot turn-out (heel→foot_index angle from sagittal plane, screen coords)
def foot_turnout(heel, foot_index): # screen (x,y) only
  foot_vec = np.array([foot_index.x - heel.x, foot_index.y - heel.y])
  forward = np.array([0, -1]) # y decreases upward in image
  return np.degrees(np.arctan2(foot_vec[0], -foot_vec[1]))

Stability Knee Valgus · Heel Lift
# Knee valgus — min inter-knee x distance in first 20% of concentric phase
# Uses SCREEN coords — valgus is lateral collapse visible in camera plane
def knee_valgus(left_knee, right_knee): # screen x only
  return abs(left_knee.x - right_knee.x) # smaller = more cave

# Find worst cave point in first 20% of concentric window
concentric_start = frame after bottom where hip_y starts decreasing
window_end = concentric_start + 0.20 * (top_frame - bottom_frame)
valgus_frames = frames[concentric_start : window_end]
min_dist = min(knee_valgus(f.left_knee, f.right_knee) for f in valgus_frames)
valgus_idx = (index of min_dist - concentric_start) / (window_end - concentric_start)
valgus_phase = "EARLY" if valgus_idx < 0.33 else "MID" if < 0.66 else "LATE"

# Heel lift — world y-axis rise from standing baseline
baseline_heel_y = avg(heel.world.y at top frame) # standing reference
max_heel_y = max(heel.world.y across all rep frames)
heel_lift_detected = (max_heel_y - baseline_heel_y) > 0.02 # 2cm threshold

Consolidated — Cross-Rep Aggregation
Trend calculation (applies to key metrics)
# Linear slope across reps — positive = worsening, negative = improving
import numpy as np

def trend_slope(values):
  x = np.arange(len(values))
  slope, _ = np.polyfit(x, values, 1)
  return round(slope, 4) # per-rep change

# Applied to: back_angle_max, knee_angle_min, knee_valgus_distance, tempo.total
back_angle_trend = trend_slope([r.back_data.back_angle_max for r in reps])
depth_trend = trend_slope([r.depth_data.knee_angle_min for r in reps])
knee_valgus_trend = trend_slope([r.stability_data.knee_valgus_distance for r in reps])
tempo_trend = trend_slope([r.tempo_data.total for r in reps])
